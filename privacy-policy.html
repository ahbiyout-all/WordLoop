WordLoop Privacy Policy

개인정보처리방침 (Privacy Policy)

시행일자: 2026년 10월 18일

🔒 로컬 퍼스트(Local-First) 원칙 안내
WordLoop(이하 "앱")는 이용자의 개인정보 및 프라이버시를 최우선으로 생각합니다. 본 앱은 별도의 회원가입이나 중앙 서버 데이터베이스 없이 작동하며, 모든 학습 데이터와 설정값은 이용자의 기기 내부에만 로컬 저장됩니다.

1. 수집하는 개인정보 항목 및 보관 방법

WordLoop는 중앙 서버로 이용자의 식별 정보를 일체 전송하거나 수집하지 않습니다.

  • 학습 데이터 (단어장, 문장장, 퀴즈 기록, 학습 레벨): 이용자 기기의 웹 브라우저 로컬 저장소(IndexedDB / LocalStorage)에만 저장됩니다.
  • 동기부여 사진 및 메시지 (부모님 사진/잔소리): 이용자가 직접 기기에서 등록한 사진은 기기 내부 브라우저 저장소(IndexedDB)에만 암호화/인코딩되어 보관되며 외부 서버로 절대 전송되지 않습니다.
  • 음성 데이터 (마이크 및 발음 평가): 기기 표준 Web Speech API를 통해 실시간 기기 내 음성 인식에만 사용되며, 음성 원본은 녹음되거나 외부로 전송·저장되지 않습니다.
  • 개인 API 키 (BYOK - 선택 사항): 이용자가 직접 입력한 Gemini API 키는 기기 로컬 스토리지에만 저장되며, AI 요청 시에만 구글 공식 API 엔드포인트와 직접 통신합니다.

2. 개인정보의 이용 목적

  • 이용자 맞춤형 영어 단어 및 문장 반복 학습, 쉐도잉 청취 기능 제공
  • 기기 내 퀴즈 결과 점수 누적 및 학습 통계 시각화
  • 오프라인 학습 지원 및 사용자 로컬 백업/복원 파일 생성

3. 기기 접근 권한 안내 (Permissions)

  • 마이크(Microphone) 권한 (선택): 영어 발음 평가 및 쉐도잉 말하기 연습 기능을 위해 사용됩니다.
  • 파일/사진 접근 권한 (선택): 부모님 동기부여 사진 등록 및 단어장 백업(JSON/CSV) 파일 내보내기/가져오기에 사용됩니다.

4. 제3자 제공 및 위탁

본 앱은 원칙적으로 이용자의 개인정보를 제3자에게 제공하거나 외부에 위탁하지 않습니다. 단, 이용자가 직접 개인 AI API 키를 입력하여 AI 기능을 실행하는 경우에 한하여 구글의 공식 API 서비스 규정에 따라 요청문이 전달됩니다.

5. 데이터의 파기 및 백업 관리

이용자는 언제든지 앱 내부의 [데이터 초기화] 기능을 통해 기기에 저장된 모든 학습 기록과 사진을 즉시 영구 삭제할 수 있으며, 앱 삭제 또는 브라우저 캐시 삭제 시 모든 데이터는 즉각 파기됩니다.
