## 📌 1. 깃허브 페이지(GitHub Pages) 활성화 및 연동 방법

WordLoop 프로젝트는 GitHub Actions를 통한 **'무중단 자동 배포(Continuous Deployment)'** 환경이 이미 완벽히 구축되어 있습니다.

### 🚀 저장소(GitHub)에서 딱 1번만 설정하는 방법:
1. 내 깃허브 저장소 페이지 접속: `https://github.com/<내계정>/<저장소명>`
2. 상단 탭에서 **[Settings]** 클릭
3. 좌측 사이드바 메뉴에서 **[Pages]** 클릭
4. **Build and deployment > Source** 옵션 설정:
   - **권장 방식**: **`GitHub Actions`** 를 선택합니다.
   - (설정 끝!) 이제 `main` 또는 `master` 브랜치로 코드를 `git push`할 때마다 `.github/workflows/deploy-pages.yml`이 실행되어 최신 버전의 앱이 몇 초 만에 자동 배포됩니다.
5. 배포 완료 후 전 세계 어디서나 접속 가능한 내 웹앱 주소:
   👉 `https://<내계정>.github.io/<저장소명>/`
6. 구글 플레이스토어에 제출할 개인정보처리방침(Privacy Policy) 공용 URL:
   👉 `https://<내계정>.github.io/<저장소명>/privacy-policy.html`

## 💰 2. 플레이스토어 1,000원 판매(유료 앱) 비즈니스 모델(BM) 분석

### (1) 시장 경쟁력 및 포지셔닝: "커피 한 잔보다 싼 1,000원 평생 소장"
- **기존 어학 앱의 피로감**: 듀오링고, 말해보카, 산타토익 등 대다수 어학 앱은 **월 9,900원 ~ 19,000원 정기 구독제**를 강제하여 사용자들의 경제적 피로도가 극에 달해 있습니다.
- **WordLoop 1,000원의 마케팅적 파괴력**:
  - **"광고 평생 제로(No Ads)"**
  - **"매월 나가는 구독료 제로(No Subscription)"**
  - **"단돈 1,000원에 평생 소장하는 나만의 영어 반복 트레이너"**
- 이 세 가지 카피만으로도 학부모, 수험생, 직장인 타겟층에서 저항감 없이 구매를 이끌어낼 수 있습니다.

### (2) 서버 유지비용 0원의 엄청난 마진 구조
- 일반적인 앱은 사용자가 늘어날수록 AWS/클라우드 서버비가 급증하여 적자가 발생합니다.
- **WordLoop는 100% 로컬 퍼스트(Local-First)** 구조로, 모든 학습 데이터가 사용자의 스마트폰 내부(IndexedDB)에 저장됩니다.
- 즉, **다운로드가 10만 건이 되든 100만 건이 되든 개발자가 부담해야 할 서버 고정비용이 0원**입니다.

### (3) 정산 및 수익 시뮬레이션 (구글 15% 우대 수수료 적용)
- 구글 플레이는 연간 누적 매출 100만 달러 이하의 모든 개발자에게 **15% 우대 수수료**를 적용합니다.
- **1건 판매당 정산액 (1,000원 기준)**:
  - 소비자 결제 금액: 1,000원
  - 부가세(VAT 10% 제외 공급가액): 약 909원
  - 구글 수수료(15%): 약 136원
  - **건당 개발자 실수령 순익: 약 773원 (순마진율 약 77%)**
- **수익 예시**:
  - 누적 1,000건 판매: 약 **77만 원** (서버비 0원이므로 100% 순이익)
  - 누적 5,000건 판매: 약 **386만 원**
  - 누적 20,000건 판매: 약 **1,546만 원**

## ⚠️ 3. 플레이스토어 유료 앱 출시 시 현실적 허들 및 통과 전략

### ① [필수 허들] 2023년 말 개정된 구글 개인 개발자 "20명 14일 비공개 테스트"
- **구글 정책**: 2023년 11월 이후 생성된 개인 개발자 계정은 프로덕션 출시 전 **최소 20명의 테스터가 14일간 앱을 설치하고 피드백을 주는 '비공개 테스트(Closed Test)'**를 통과해야 정식 출시가 승인됩니다.
- **극복 전략**:
  1. **오픈채팅/커뮤니티 품앗이**: 카카오톡 오픈채팅방에 "구글 플레이 20명 테스터 품앗이" 방이 매우 활성화되어 있습니다. 서로의 앱을 깔아주고 14일을 채우는 방식으로 비용 없이 1~2주 내 완료 가능.
  2. **지인 및 스터디 그룹**: 영어 공부를 하는 지인, 학부모, 동호회에 테스터 링크를 공유.
  3. **크몽/외주 플랫폼 활용**: 급한 경우 2~3만 원 선에서 20명 테스터 세팅 대행 서비스를 이용할 수도 있습니다.

### ② [필수 제출] 개인정보처리방침 (Privacy Policy URL)
- 유료 앱은 구글 정책상 반드시 웹에 게시된 개인정보처리방침 URL을 제출해야 합니다.
- **해결책 완비**: 본 프로젝트 `public/privacy-policy.html`이 빌드 시 자동으로 포함되므로, GitHub Pages 주소(`https://<아이디>.github.io/<저장소>/privacy-policy.html`)를 그대로 입력하시면 구글 심사를 100% 통과합니다.

### ③ 유료 앱 구매자의 AI 기능 기대치 관리 (BYOK 안내)
- 1,000원을 결제한 사용자가 "AI 단어 생성이나 롤플레이를 하려니 구글 API 키를 넣으라고 하네요?"라며 1점 평점을 주는 것을 방지해야 합니다.

## 🛠️ 4. 안드로이드 APK / AAB 빌드 및 출시 절차 (Capacitor)

현재 프로젝트에는 `@capacitor/android`가 이미 구성되어 있습니다.

```bash
# 1. 최신 웹 소스 빌드
node scripts/build-web.js

# 2. 안드로이드 스튜디오 프로젝트 동기화
node scripts/sync-android.js

# 3. Android Studio 실행
npx cap open android
```

### Android Studio에서의 작업:
1. `Build` > `Generate Signed Bundle / APK` 클릭
2. `Android App Bundle (AAB)` 선택 (구글 플레이스토어 제출용 필수 포맷)
3. 서명 키(Keystore) 생성 및 서명 빌드 완료
4. 생성된 `.aab` 파일을 구글 플레이 콘솔(Google Play Console)에 업로드!
