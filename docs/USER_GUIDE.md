# WordLoop 사용자 가이드 (User Guide · v4.5.1)

---

## 1. 오늘의 3분 루틴 시작하기 (`TodayHub`)
1. 앱 상단 **`[오늘 학습]`** 탭에서 현재 복습이 필요한 단어 수와 오늘의 추천 5단어를 바로 확인할 수 있습니다.
2. **`[오늘의 3분 루틴 시작]`** 버튼을 누르면 집중 루틴 플레이어가 열립니다:
   - **Step 1 (듣기 & 뜻 확인):** 원어민 발음으로 단어와 학년별 실생활 예문을 확인합니다.
   - **Step 2 (4지선다 회상):** 방금 학습한 단어의 뜻을 4개 보기 중 골라 즉시 확인합니다.
   - **Step 3 (SM-2 자기 평가):** `다시(Again) / 어려움(Hard) / 적당(Good) / 쉬움(Easy)` 버튼으로 다음 복습 일정을 자동 예약합니다.

---

## 2. AI 음소(Phoneme) 단위 발음 교정 리포트
단어 카드의 **`🎙️ 발음 연습`** 버튼 또는 루틴 중 발음 훈련에서 사용할 수 있습니다:
1. 마이크 버튼을 누르고 단어나 문장을 또렷하게 발음합니다.
2. 인식 직후 **발음 교정 리포트**가 열리며, 각 음소별 자소(예: `th`, `r`, `v`)와 표준 IPA 대비 실제 발음 차이(`/θ/→/s/`, `/r/→/l/`, 어말 자음 탈락 등)를 색상 배지로 표시합니다.
3. 교정이 필요한 음소를 클릭하면:
   - **구강 단면도 SVG:** 혀끝·치아·입술·잇몸의 목표 조음 위치와 기류 방향을 그래픽으로 안내합니다.
   - **구간 비교 재생:** `원어민 듣기`, 내 녹음에서 해당 음소 구간만 잘라 듣는 `내 발음 구간 듣기`, 그리고 `think ↔ sink` 같은 **최소대립쌍(Minimal Pair)** 연속 비교를 제공합니다.
   - 개인 Gemini API 키가 등록된 경우 실제 녹음 오디오를 기반으로 서버 사이드 AI 정밀 음소 분석이 자동 보강됩니다.

## 3. 사전 검색 · 단어장 · 3단계 암기 관리
- **`[단어장]` 탭:** 초등·중학·고등/수능 커리큘럼 3,210단어와 학년별 맞춤형 예문을 탐색하고 검색/필터링할 수 있습니다.
- **3단계 숙련도 배지:** 🔴 `0단계 (미암기)` · 🟡 `1단계 (학습중)` · 🟢 `2단계 (완벽암기)`를 원클릭으로 전환할 수 있으며 SM-2 스케줄과 자동 연동됩니다.
- **상업용 오픈 사전 검색:** 내장 사전에서 즉시 찾고, 없는 어휘는 FreeDictionaryAPI + Wiktionary + 무료 AI(또는 Gemini)를 통해 뜻·IPA·뉘앙스·예문을 자동 생성해 단어장에 추가합니다.

## 4. 로컬 저장소 용량 관리 & JSON 스마트 병합 백업
WordLoop는 회원가입 없이 100% 본인 기기의 브라우저 저장소(5MB 한도)에 데이터를 보관합니다.
1. 상단 프로필 또는 백업 메뉴에서 **`JSON 백업 / 복원`** 모달을 엽니다.
2. **`로컬 저장소 점유율 게이지`**에서 현재 사용률(%)과 키별 용량을 확인할 수 있습니다.
3. 용량이 높게 표시될 경우 **`[JSON 백업 후 캐시 정리]`** 버튼을 누르면 Schema v2 백업 파일을 다운로드한 뒤 구버전 중복 캐시·긴급 스냅샷을 안전하게 압축/정리합니다.
4. 백업 파일 불러오기 시 **추가·업그레이드·유지 항목 수(Diff Preview)**를 먼저 확인한 뒤 **스마트 병합(Smart Merge)** 또는 전체 덮어쓰기를 선택할 수 있으며, 실행 직전 자동 롤백 스냅샷이 생성됩니다.

## 5. API 키 없는 7중 무료 AI 엔진 & 선택적 Gemini API Key 설정
WordLoop는 별도 API 키 없이도 **전 세계 무료 AI 7중 자동 체인**을 즉시 제공합니다.
1. 상단 설정 메뉴에서 **`[무료 AI 엔진 · API 키]`**를 엽니다.
2. 총 9가지 옵션 중 원하는 모드를 선택하고 **`[무료 AI 연결 테스트]`**로 응답 속도를 바로 확인할 수 있습니다:
   - **무료 AI 7중 자동 워터폴 (추천):** OVHcloud 70B/DeepSeek · Kilo 550B · Pollinations · Workers AI · LLM7 · MLVoca · 온디바이스 Gemini Nano를 자동 순환 연결합니다.
   - **개별 무료 엔진:** `Kilo AI Gateway (550B · 프록시)`, `OVHcloud EU AI (DeepSeek V4.1/Llama 70B · 브라우저 직결)`, `Pollinations AI`, `Cloudflare Workers AI`, `LLM7 Open Gateway`, `MLVoca Ollama (DeepSeek R1/TinyLlama)`, `Chrome 내장 온디바이스 AI (Gemini Nano)`.
3. 녹음된 원음 오디오를 직접 청취하는 멀티모달 발음 진단을 원할 때만 선택적으로 Google AI Studio 키(`x-gemini-api-key`)를 입력해 활용하세요.
