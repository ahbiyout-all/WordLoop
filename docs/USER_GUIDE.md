# WordLoop 사용자 가이드 (User Guide)

---

## 1. 사전 검색 및 단어장 추가
1. **상단 [상업용 사전 검색] 탭 클릭**:
   - 검색창에 영어 단어(예: `resilience`, `persistence`)를 입력합니다.
   - 코드 내 내장 사전 데이터베이스에 저장된 단어는 즉시 검색되며, 그 외 단어는 FreeDictionaryAPI와 Gemini AI 연동을 통해 한국어 뜻, IPA 발음기호, 뉘앙스 팁, 예문이 자동 생성됩니다.
2. **[단어장에 추가] 버튼**: 검색된 카드의 우측 상단 버튼을 눌러 내 단어장에 보관합니다.

---

## 2. 3단계 암기 정도 관리 (Mastery Level)
모든 단어 및 문장 카드에는 3단계 암기 표시 배지가 제공됩니다:
- 🔴 **미암기 (0단계)**: 아직 외우지 못했거나 자주 틀리는 단어.
- 🟡 **학습중 (1단계)**: 뜻은 알지만 복습이 필요한 단어.
- 🟢 **완벽암기 (2단계)**: 완전히 암기하여 테스트를 통과한 단어.

---

## 3. 학습 옵션 & 도구 모달 (Options & Tools)
단어장 탭 우측 상단의 **[학습 옵션 & 도구]** 버튼을 클릭하면 한곳에서 모든 학습 모드를 제어할 수 있습니다:
1. **뜻 가리기**: 카드의 한국어 뜻을 숨겨 자가 암기 테스트(Active Recall)를 진행합니다.
2. **북마크만 표시**: 중요 체크해둔 카드만 모아봅니다.
3. **암기 단계 필터**: 미암기(0단계), 학습중(1단계), 완벽암기(2단계) 카드만 선택하여 집중 학습합니다.
4. **CSV / JSON 백업 및 복원**:
   - `CSV 백업`: 엑셀에서 열어볼 수 있는 파일로 내 단어장을 내보냅니다.
   - `JSON 백업`: 전체 단어장, 문장 및 암기 상태를 원본 파일로 백업합니다.
   - `백업 복원`: CSV 또는 JSON 백업 파일을 업로드하여 단어장을 원상 복원합니다.

---

## 4. 퀴즈 모드 & 오답노트 (Quiz & Wrong Answer Notes)
상단 **[퀴즈 모드]** 탭에서 제공하는 기능:
1. **🎴 플래시카드**: 단어 카드를 뒤집어가며 음성과 함께 암기 상태를 체크합니다.
2. **🧩 4지선다 퀴즈**: 4개의 뜻 보기 중 정답을 맞히면 점수를 획득하며, 정답 시 암기 단계가 자동 승급됩니다.
3. **📓 오답노트**: 퀴즈 및 플래시카드에서 틀리거나 '복습 필요'로 지정한 단어가 자동으로 모여 집중 복습할 수 있습니다.

---

## 5. 개인 전용 Gemini API Key (BYOK) 설정 가이드
개인 모바일 장치나 웹 브라우저에서 단독으로 사용할 때, 자신만의 Gemini API 키를 등록하여 사용하실 수 있습니다.
1. **[API Key] 버튼 클릭**: 상단 네비게이션 우측의 `[API Key]` 또는 `🔑` 버튼을 클릭합니다.
2. **무료 API Key 발급**: Google AI Studio(`aistudio.google.com/app/apikey`)에 접속하여 구글 계정으로 무료 API 키를 발급받습니다.
3. **키 입력 및 저장**: 발급받은 `AIzaSy...` 키를 붙여넣고 **[연결 테스트]** 후 **[저장하기]**를 클릭합니다.
4. **보안 지침**: 등록된 키는 브라우저 `localStorage`에만 안전하게 보관되며 서버 DB 등에 보관되지 않으므로 안심하고 사용하실 수 있습니다.
