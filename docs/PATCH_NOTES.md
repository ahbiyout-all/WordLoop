## 🚀 Version 3.43.0

### 🛡️ 전방위 풀스택 보안 강화(Full-Stack Security Hardening) & CSRF·DoS·인젝션 방어선 구축
- **🌐 비인가 교차 출처(Cross-Origin) API 요청 차단 및 CSRF 방어 (`server.ts`)**:
  - `/api/*` 경로의 모든 데이터 변경 및 API 요청에 대해 엄격한 `Origin` 및 `Referer` 검증 미들웨어를 도입했습니다.
  - 인가된 출처(localhost, 127.0.0.1, Google Cloud Run `*.run.app`, Google Workspace `*.google.com`, 네이티브 앱 스킴 `capacitor://`, `app://`, `file://`)만을 허용하고 외부 제3자 사이트의 비인가 교차 출처 API 호출 및 CSRF 시도를 HTTP 403 Forbidden으로 원천 차단합니다.
- **⏱️ 이중 티어(Dual-Tier) Rate Limiting & DoS 방어 (`server.ts`)**:
  - 일반 API는 분당 60회, 고비용 AI 생성 엔드포인트(`/api/ai/*`)는 분당 20회로 엄격하게 분리 제한하고 `Retry-After: 60` 헤더를 지원하여 서비스 거부 공격 및 Gemini API 쿼터 남용을 방지합니다. 만료된 메모리 버킷을 주기적으로 청소하여 메모리 누수를 방지합니다.
- **🔒 강화된 보안 응답 헤더(HTTP Security Headers) 체계 (`server.ts`)**:
  - `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `X-Download-Options: noopen`, `X-Permitted-Cross-Domain-Policies: none`, `X-DNS-Prefetch-Control: off`, `Cross-Origin-Opener-Policy: same-origin-allow-popups`를 전면 활성화했습니다.
  - `Permissions-Policy`를 통해 불필요한 카메라/지오로케이션/결제 센서 권한을 비활성화하고, 발음 평가에 필요한 마이크 권한만 인가했습니다.
  - CSP `frame-ancestors 'self' https://*.google.com https://*.run.app https://*.aistudio.google.com;`를 적용하여 악의적인 클릭재킹(Clickjacking)을 방어하면서 안전한 미리보기를 제공합니다.
- **🧼 프롬프트 인젝션 & XSS 살균 정화 및 심층 객체 보호 (`server.ts`, `deviceStorageService.ts`)**:
  - 입력 텍스트 정화(`sanitizeInputText`)에서 Null Byte 제거, 악성 스크립트 태그(`script`, `iframe`, `object`, `javascript:`, 이벤트 핸들러) 필터링, 시스템 프롬프트 탈옥 구문(`ignore previous instructions` 등)을 사전 무력화했습니다.
  - `sanitizeDeepObject`를 구현하여 외부 JSON 백업 복원 시 Prototype Pollution(`__proto__`, `constructor`, `prototype`)을 원천 차단하고 재귀 깊이를 엄격히 제한했습니다.
- **🖼️ 이미지 업로드 보안 및 캔버스 정규화 (`parentPhotoUtils.ts`)**:
  - 부모님 사진 등록 시 10MB 크기 상한을 적용하여 이미지 폭탄(Image Bomb) 메모리 고갈 공격을 방어했습니다.
  - SVG 업로드 시 스크립트 벡터를 정화하고, 오프스크린 캔버스를 통해 무해한 JPEG 레스터 데이터로 정규화하여 저장합니다.
- **🔔 비차단 온스크린 알림 표준화 (`App.tsx`)**:
  - 브라우저 블로킹 `alert()` 호출을 제거하고 세련된 온스크린 토스트(`setRecoveryToast`)로 통일하여 안전하고 쾌적한 UX를 보장합니다.

- **⚡ deprecated 모델 교체 (404 Not Found 원천 해결)**:
  - 구글의 `gemini-2.5-flash` 지원 종료로 인해 발생하던 `404 Not Found` 오류를 해결하기 위해, 공식 권장 최신 고성능 모델인 `gemini-3.6-flash`, `gemini-3.8-flash`, `gemini-flash-latest`로 백엔드 전체 API(`/api/dictionary/lookup`, `/api/ai/generate-vocab`, `/api/ai/explain`, `/api/ai/recommend-goals`)를 전면 업그레이드했습니다.

  - 문장 및 단어 클릭 시 **표준 IPA 발음 기호, 핵심 어휘 품사 분석, 원어민 억양(Rhythm) 및 연음(Linking) 쉐도잉 팁**을 0.05초 만에 즉시 해설합니다.
- **📚 스마트 어휘 및 맞춤 목표 추천 복원력 강화**:
  - 단어 생성기 및 자기계발 목표 추천기에서도 API 장애 시 3,210개 표준 어휘 및 난이도별 최적 커리큘럼에서 자연스럽게 자동 추천되어 빈 화면이나 에러 모달 없이 항상 정상 작동합니다.
- **⏱️ 외부 공개 사전 API 타임아웃 안전망(AbortSignal) 적용**:

## 📜 Version 3.1.0
- **✨ 원라인(Single-line) 가로 터치 정렬 & 텍스트 줄바꿈 완전 제거**:

- **⚡ 간결하고 직관적인 상태 라벨 적용**:
  - 버튼 레이블을 `[재생 / 일시정지]`, `[한글 ON / OFF]`, `[발음 쉐도잉]`으로 직관적으로 다듬어, 터치 반응성과 시각적 가독성을 대폭 향상했습니다.
- **✕ 플레이어 즉각 종료(X) 원탭 닫기 버튼 추가**:
  - 연속 청취 학습을 마치거나 화면을 넓게 보고 싶을 때, 우측 상단의 `✕` 버튼을 1탭 하면 오디오 재생이 즉시 중단되면서 하단 바가 깔끔하게 닫힙니다.
- **🔽 플로팅 미니 플레이어(Pill) 모드 지원**:
  - 하단 접기(`⌄`) 버튼을 누르면 화면 아래쪽에 작고 우아한 플로팅 알약(Floating Pill) 형태로 축소되어, 메인 단어/문장 카드를 전혀 가리지 않고도 배경에서 연속 반복 청취 및 재생/정지를 제어할 수 있습니다.
- **🛡️ 뷰포트 하단 동적 안전 여백(Safe Padding) 연동**:
  - 하단 플레이어가 켜져 있을 때도 최하단 카드와 각종 액션 버튼들이 가려지지 않도록 메인 뷰포트에 동적 스크롤 여백(`pb-32`)을 연동했습니다.

- **🔄 통합 비상 복구 스냅샷 (Crash Recovery Engine)**:
  - 예기치 않은 비정상 종료 후 앱을 재실행했을 때, 최근 24시간 이내의 비상 스냅샷 무결성을 자동 검증하고 `"이전 세션의 모든 학습 데이터가 손실 없이 100% 안전하게 복원되었습니다."` 안내 토스트와 함께 온전하게 로드합니다.
- **💾 원자적 이중화 저장 (Atomic Backup Ledger)**:
  - 개별 로컬 스토리지 키 저장 외에도 전체 묶음 비상 스냅샷과 안전 감사 원장(`wordloop_atomic_safety_ledger`)을 실시간 동기화하여 파일 손상 및 부분 저장 오류를 원천 차단합니다.

- **🏷️ 내 선택(⭕/❌) vs 실제 정답(⭕/❌) 실시간 뱃지 비교**:
  - 내가 고른 선택지와 실제 문제의 진위 판정 결과를 상단 뱃지로 명확하게 대조 표시합니다.

- **🧩 1. 문장 어순 블록 조립 (Chunk Builder)**:
  - 흩어진 단어 청크 블록을 어순에 맞게 클릭/탭하여 완성도 높은 영어 문장을 완성하는 어순 빌더 게임을 탑재했습니다.
  - 선택한 블록을 취소하거나 다시 배치할 수 있으며, 원어민 음성 듣기 및 한국어 뜻 힌트를 지원합니다.
- **🎧 2. 리스닝 청취 빈칸 채우기 (Dictation Fill-in)**:
  - 원어민 음성을 듣고 문장 속 핵심 빈칸에 알맞은 단어를 4지선다 중에서 고르는 인터랙티브 받아쓰기 챌린지입니다.
  - 단어 품사, 문맥 힌트, 무제한 다시 듣기 버튼을 지원합니다.
- **⚡ 3. 스피드 문장 완성 퀴즈 (Speed Rush)**:
  - 30초 타임어택 동안 제시된 한글 뜻에 맞는 정확한 영어 문장을 빠르게 고르는 순발력 퀴즈입니다.
  - 연속 정답 시 콤보 보너스 점수 및 시간 연장 혜택이 주어집니다.
- **🕵️‍♂️ 4. 문장 오류 & 진위 판별 (Error Hunter True/False)**:
  - 제시된 문장의 문법/어휘 오류 및 한국어 번역 일치 여부를 O/X로 신속하게 판별하는 문장 감별 챌린지입니다.
  - 정답 판별 후 상세한 해설과 올바른 문장 구조를 즉시 확인하여 문법 실력을 향상시킬 수 있습니다.
- **🎙️ 5. 쉐도잉 발음 판정 챌린지 (AI Speech Shadowing)**:
  - 원어민 소리를 듣고 마이크로 직접 따라 말하면 실시간 Web Speech API 음성 인식을 통해 단어별 일치율과 발음 정확도를 별점(★) 점수로 채점해줍니다.
- **🎮 게임 천국 단어(8종) / 문장(5종) 듀얼 허브 개편**:
  - 게임 천국 메인 화면에서 [단어 게임 (8종)]과 [문장 게임 (5종)]을 상단 탭으로 즉시 전환할 수 있는 직관적인 듀얼 카탈로그 허브를 구축했습니다.
  - 교육부 교육과정 3,210단어 및 학년별(초등/중학/고등·수능/전체) 문장 데이터와 사용자 커스텀 문장이 완벽하게 연동됩니다.
- **✏️ 스펠링 완성 퀴즈 가독성 및 UI 시각성 개선**:
  - 스펠링 완성 퀴즈 조립 슬롯과 하단 알파벳 후보 블록의 크기를 대폭 확대하고, 하단에 실제 활용 예문 박스를 추가하여 문맥 학습을 강화했습니다.
