## 📜 Version 3.11.2

### 🛡️ 앱 실행 시 하얀색 창 멈춤(White Screen of Death) 현상 원천 차단 및 Electron 패키징 완전 안정화
- **🖥️ Electron `file://` CORS 및 ES 모듈 로딩 완벽 해결**:
  - Chromium 보안 정책으로 인해 로컬 `file://` 환경에서 ES 모듈 스크립트 실행이 차단되던 문제를 해결하기 위해, `allow-file-access-from-files` 플래그 및 `webSecurity: false` 옵션을 적용하고, 웹 빌드 후처리 단계에서 `dist/index.html` 내 `crossorigin` 속성을 자동 정돈하여 오프라인/로컬 파일에서도 스크립트가 100% 정상 로드되도록 개편했습니다.
- **📦 Electron-Builder `dist` 누락 방지 & 다중 진입 경로 자동 탐색**:
  - `.gitignore` 규칙으로 인해 electron-builder 패키징 시 `dist/` 폴더가 번들에서 누락되어 발생하던 `FILE_NOT_FOUND` 빈 화면 버그를 해결했습니다. `package.json` 및 `scripts/build-electron.js`에 `dist/**/*`를 명시적 패키징 대상에 추가하고, 앱 진입 경로를 asar, 상대 경로, 리소스 경로 순으로 안전하게 자동 탐색하도록 개선했습니다.
- **🔄 글로벌 React Error Boundary & 인라인 다크 프리로더 구축**:
  - 예기치 못한 런타임 렌더링 오류가 발생하더라도 백색 화면으로 멈추지 않고, 친절한 안내와 함께 **[앱 다시 로드하기]**, **[캐시 초기화 후 재실행]** 복구 버튼을 제공하는 `<ErrorBoundary>`를 전역 적용했습니다.
  - `index.html` 자체에 다크 테마 인라인 스플래시 화면을 내장하여, 앱 초기 로딩 중 나타나던 하얀색 화면 점멸을 완전히 제거했습니다.
- **🔒 로컬 저장소(LocalStorage) 상태 안전 파싱 방어선 구축**:
  - 목표(goals), 학습 히스토리(history), 반복 횟수 등의 로컬 캐시 파싱 과정을 전수 `try/catch`로 보호하여, 손상된 캐시 데이터가 있더라도 기본 데이터로 안전하게 복원되어 즉시 실행되도록 개선했습니다.

### 🎯 QuizMode 내 취약 어휘(0~1단계) 맞춤 집중 복습 퀴즈 (Review Quiz) 신설
- **🎯 취약 어휘(Mastery Level 0 & 1) 정밀 타겟팅**:
  - 학습자의 어휘 목록 중 마스터 등급 0단계(미암기) 및 1단계(학습중) 단어만을 추출하여, 가장 취약한 어휘군을 집중적으로 마스터할 수 있도록 돕는 전용 ‘Review Quiz’ 모드를 추가했습니다.
- **📈 정답 시 실시간 등급 승급 시스템 (0단계 ➔ 1단계 ➔ 2단계 마스터)**:
  - 퀴즈에서 문제를 맞힐 때마다 단어의 마스터 레벨이 0단계(미암기)에서 1단계(학습중)로, 1단계에서 2단계(완벽 암기)로 즉시 승급되며, 화면에 실시간 승급 알림 배너가 표시됩니다.
- **💡 오답 정밀 피드백 & 0단계 유지 안전망**:
  - 오답 선택 시 정답 단어, 발음기호, 정확한 한국어 뜻, 예문 및 번역, 원어민 발음 듣기 버튼이 포함된 분석 카드가 노출되며, 해당 단어는 0단계(미암기)로 유지되어 다시 출제됩니다.
- **📊 상단 취약 어휘 카운터 & 세션 완료 리포트 대시보드**:
  - 퀴즈 진행 중 상단 바에 미암기(0단계) 및 학습중(1단계) 어휘 수, 승급 개수를 실시간으로 표시하며, 세션 완료 시 획득 점수·승급 개수·남은 취약 어휘 수를 한눈에 확인할 수 있는 완료 대시보드를 제공합니다.
- **🎲 메인 런처 및 34종 랜덤 학습 생성기 연동**:
  - 메인 런처의 퀴즈 카드와 랜덤 액티비티 생성기에 '취약 어휘(0~1단계) 집중 복습 퀴즈' 항목을 등록하여 원클릭으로 바로 취약 어휘 집중 퀴즈에 진입할 수 있도록 연결했습니다.

### 🧱 알파벳 블록 팡 중력 물리 엔진 & 스테이지 확장 시스템 대규모 개편
- **중력 물리 낙하 시스템**: 알파벳 블록을 클릭하여 맞추면 기존 블록이 팡! 터지며 사라지고, 위에 위치한 블록들이 중력에 의해 아래 빈 공간으로 자연스럽게 떨어집니다.
- **상단 공중 스폰 리필 (Top Fall-in)**: 상단 첫 줄에 빈 공간이 생기면 새로운 알파벳 블록들이 공중에서 떨어져 그리드를 지속적으로 채웁니다.
- **클리어 조건 & 스테이지 레벨업**:
  1. 보드 상의 모든 알파벳 블록을 없애거나(All Clear 보너스)
  2. 스테이지 목표 점수 이상을 달성하면 게임 클리어 및 다음 단계로 진행!
- **단계별 가로세로 그리드 확장**: 다음 단계(Stage)로 진행될 때마다 블록 그리드 크기가 1씩 증가합니다 (1단계: 4×4 → 2단계: 5×5 → 3단계: 6×6 → 4단계: 7×7).
- **아케이드 시각/효과음 강화**: 경쾌한 버블 팝 파티클 폭발 및 Web Audio 신시사이저 사운드 연동.

## 📜 Version 1.6.0

### 🎮 5종 단어 학습 게임 모바일 원스크린(100dvh) 완벽 대응 & 반응형 최적화
- **스크롤 없는 모바일 게임 환경**: 스마트폰 화면 크기(`100dvh`)에 최적화하여 5종 단어 학습 게임(크로스워드, 단어 블록, 스와이프 매칭, 방울 팡, 리듬 노트)이 한 화면에서 스크롤 없이 부드럽게 작동.
- **크로스워드 가상/물리 키패드 & 탭 전환**: 화면 크기에 따라 퍼즐 판과 힌트 영역을 모바일 전용 탭(`board` / `clues`)으로 원터치 전환하고 물리 키보드 및 온스크린 키패드 입력을 완벽 연동.
- **3대 Q&A 학습 모드 전면 지원**:
  1. `ko_to_en`: 한국어 뜻을 보고 영어 단어 맞히기
  2. `en_to_ko`: 영어 단어를 보고 한국어 뜻 맞히기
  3. `def_to_en`: 영어 정의(영영 풀이)를 보고 알맞은 단어 맞히기
- **자동 패치노트 & 버전 관리 시스템 정립**: 코드 수정의 특이점(주요 업데이트 및 개편) 발생 시 자동으로 패치노트 기록 및 버전 동기화 관리.

## 📜 Version 1.4.0

### 🔑 개인 전용 Gemini API Key (BYOK: Bring Your Own Key) 모드 적용
- **개인 단독 사용자 전용 BYOK 시스템**: 개인 모바일 및 웹 환경에서 단독으로 사용할 때 자신의 Gemini API 키를 등록하여 인원 제한이나 서버 할당량 제약 없이 안전하게 이용 가능.
- **안전한 LocalStorage 보관**: 키는 외부 서버나 DB에 보관되지 않으며, 사용자의 브라우저 이격 공간(`localStorage`)에 보관되고 API 요청 시 헤더(`x-gemini-api-key`)로만 전달됩니다.
- **네비게이션 상단 API Key 모달**: 상단 네비게이션의 `[API Key]` 버튼을 통해 실시간 연결 테스트, 키 저장/삭제 및 무료 키 발급(Google AI Studio) 안내 제공.

## 📜 Version 1.3.0

### 1. 상업용 허용 오픈 사전 결합 및 내장 사전 DB 탑재
- **코드 내 내장 사전 (Pre-bundled Embedded Dictionary)**: `resilience`, `persistence`, `collaborate`, `sustainability`, `empathy` 등 필수 어휘에 대해 네트워크 조회 없이 즉시 조회 가능하도록 탑재.
- **오픈 라이선스 결합 사전 (1+2+5)**: FreeDictionaryAPI + Wiktionary 데이터 + Gemini AI 엔진을 통합하여 상업적 사용이 가능하며 속도와 번역 품질을 대폭 향상.

### 2. 3단계 암기 정도 관리 기능 추가
- 단순 완료/미완료 구분을 확장하여 **0단계 (미암기)**, **1단계 (학습중)**, **2단계 (완벽암기)**의 3단계 시스템 도입.
- 단어 및 문장 카드 상단에서 원클릭으로 암기 상태 변경 지원.

### 3. 학습 옵션 & 도구 단일 모달 통합 (UI Consolidation)
- 여러 곳에 흩어져 있던 복잡한 필터 및 설정 버튼을 **[학습 옵션 & 도구]** 통합 팝업 모달로 정리하여 깔끔한 UI/UX 구현.
- 뜻 가리기(자가 암기 테스트), 북마크 필터, 암기 단계별 필터, CSV/JSON 백업 및 복원 기능을 팝업창에서 손쉽게 이용 가능.

### 4. 퀴즈 모드 고도화 & 오답노트 (Wrong Answer Notebook) 기능 추가
- 4지선다 퀴즈 및 플래시카드 연동.
- 틀린 문제나 복습이 필요한 단어만 별도로 모아서 학습하고 마스터할 수 있는 **오답노트** 전용 탭 추가.
